GODS — PEOPLE PAGE UPDATE
========================

Copy these files to the corresponding paths in your GODS website:

  people.html
  assets/js/content.js
  assets/js/site.js
  assets/css/people.css    [NEW]

The people.html page already references people.css.

Leadership:
- The Principal Investigator is listed once, not twice.
- To add Gustavo's portrait, save a genuine photo as:
  assets/images/gustavo-madeira.webp
- Edit Gustavo's entry in assets/js/content.js to fill in website, ORCID,
  Lattes, or a different contact email. Empty links are hidden automatically.

Other people:
- Add entries in content.js with group 'Researchers' or 'Students'.
- Each person can have a WebP photo, affiliation, interests, ORCID and Lattes.
- Personal website links are not shown for Researchers or Students.
- Missing photo files show a monogram until the images are uploaded.

The site still uses the shared header and footer via layout.js.
There are no Collaborators or Alumni sections.

Preview through Phoenix Code Live Preview or GitHub Pages, not file://.
